# Design System: Technical Precision

## Introduction
The "Technical Precision" design system is crafted for **IMRATEL**, a telecommunications network dimensioning tool. It prioritizes clarity, technical rigor, and a professional academic aesthetic.

## Colors

### Brand
- **Primary:** `#0056B3` (Actions, active states)
- **Deep Navy:** `#002D62` (Authority, headers)
- **Accent Amber:** `#F89406` (Highlights, critical calculations)

### Neutral & Surface
- **Surface:** `#F9F9FF`
- **Surface Container:** `#F2F3FC`
- **Outline:** `#D9D9E2`
- **On-Surface:** `#212529`
- **On-Surface Variant:** `#495057`

## Typography
- **Primary Font:** Inter (Sans-serif)
- **Scale:**
  - **Display:** 32px / 40px (Bold)
  - **Headline:** 24px / 32px (Semi-bold)
  - **Title:** 18px / 24px (Medium)
  - **Body:** 16px / 24px (Regular)
  - **Label:** 14px / 20px (Medium/Bold)
  - **Code/Tech:** 14px (Monospace for formulas)

## Layout & Components
- **Grid:** Sidebar-driven desktop layout (260px fixed width).
- **Roundness:** 4px (Soft precision).
- **Buttons:** 
  - Primary: Solid blue, square with slight rounding.
  - Secondary: Outlined.
- **Inputs:** White background, subtle border, clear labels.

## Design Principles
1. **Utility First:** Design serves the calculation logic.
2. **Visual Feedback:** Instant update of results with high contrast.
3. **Academic Rigor:** Formulas and technical terms are displayed clearly.
